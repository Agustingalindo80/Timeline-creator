2) Stage 0 “Value Framing” — 1-page playbook (AE-runnable)

Purpose

Turn a sales pursuit into an investment-grade initiative: clear outcomes, measurable KPIs, realistic options, and a governed path to Stage 1.

Inputs you must have before you start
	•	Sponsor identified (name + title) and reachable
	•	Business owner / PO identified
	•	Known systems in scope (even if partial)
	•	A rough budget signal (range is fine)

Core activities (run this sequence)
	1.	Sponsor Alignment (30–45 min)

	•	Confirm why now, top pains, business urgency
	•	Confirm decision process, timeline, and success definition
	•	Lock Gate 1 date (Value Approval)

	2.	Outcome Workshop (60–90 min)

	•	Define 3–7 outcomes max
	•	For each: KPI definition, target, time horizon, owner
	•	Identify what would disprove success (keeps honesty)

	3.	Measurement + Baseline (45–60 min)

	•	Identify baseline data sources and data gaps
	•	Define measurement cadence and ownership
	•	Confirm how KPIs will be reported (dashboard/pack)

	4.	Solution Options + Phasing (60 min)

	•	Option A: MVP / Wave 1
	•	Option B: broader scope (or alternate architecture)
	•	Tradeoffs: cost/time/risk/adoption impact
	•	Explicitly define what is out of scope for Wave 1

	5.	Feasibility + Risk Sweep (45–60 min)

	•	Integration dependencies, security constraints, access lead times
	•	NFRs: performance, compliance, data retention, audit needs
	•	Adoption constraints: training capacity, process readiness

	6.	Commercial ROM + Delivery Approach (45–60 min)

	•	ROM estimate with assumptions
	•	Delivery model recommendation (FP/T&M/MS)
	•	Proposed governance cadence + roles

Deliverables (Stage 0 exit bundle)
	•	Value Narrative (1–2 pages) + stakeholder map
	•	Business Outcomes Pack (outcomes + KPIs + targets + owners)
	•	Baseline/Measurement Plan
	•	Option Set A/B with phasing logic and scope boundaries
	•	Assumptions/Dependencies/Risks log
	•	ROM Estimate + commercial recommendation
	•	Governance Proposal
	•	Stage 1 Readiness Plan (workshops, access, decisions, dates)

Gate 1: Pass/Fail criteria (no fluff)

Pass only if:
	•	Outcomes + KPIs are agreed and measurable
	•	Baseline method is defined (even if data collection continues)
	•	Sponsor commits time/resources and governance
	•	Phasing + in/out of scope is explicit
	•	Major risks/deps have owners
	•	Stage 1 kickoff is scheduled with named participants

Common failure modes (call them out early)
	•	“We’ll define KPIs later” → means value will never be proven
	•	“Yes, we can do everything in Wave 1” → guaranteed scope fight later
	•	No sponsor ownership → adoption failure dressed as “technical delays”
	•	No baseline → you’ll argue opinions at every steering committee
