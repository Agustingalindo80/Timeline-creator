Portfolio Health Score =

9. Financial Health Panel

- Earned Value
- Planned Value
- Actual Cost
- Variance at Completion

EVM formulas:
- CV = EV - AC
- SV = EV - PV
- CPI = EV / AC
- SPI = EV / PV
- EAC = BAC / CPI, where valid
- VAC = BAC - EAC
- Gross Margin % = (Revenue - Cost) / Revenue

Financial RAG:
- Green:
  - Forecast margin >= target margin
  - CPI >= 0.95
  - Cost variance within tolerance
- Amber:
  - Forecast margin below target by <= 5 percentage points
  - CPI between 0.85 and 0.95
- Red:
  - Forecast margin below target by more than 5 percentage points
  - CPI < 0.85
  - EAC materially exceeds BAC

Use configurable thresholds.
